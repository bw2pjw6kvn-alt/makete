# Makete & Alati

Osobna aplikacija za inventar maketarskog pribora, praćenje izrade maketa, sheme bojanja, želje i račune.

- Radi u pregledniku (Chrome/Edge) i na mobitelu („Dodaj na početni zaslon”).
- Nakon prvog otvaranja radi i bez interneta.
- **Podaci se ne spremaju ovdje** — ostaju samo u pregledniku na svakom uređaju. Na novom uređaju učitaj svoj backup (⚙ → Podaci → Uvoz).
